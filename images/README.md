# Image Assets

Add these files to this folder using the exact filenames below. PNG or JPEG is
fine; optimized WebP is also acceptable if the `src` paths in `index.html` are
updated.

| Filename | Used for | Recommended size | Notes |
| --- | --- | --- | --- |
| `grooming-banner.png` | Home section banner | 1600 x 600 px | Wide landscape photo; keep the dog and groomer near the center. |
| `bath-service.png` | Basic Bath & Dry card | 800 x 600 px | Landscape photo. |
| `full-groom-service.png` | Full Groom Package card | 800 x 600 px | Landscape photo. |
| `nail-trim-service.png` | Nail Trim & Ear Cleaning card | 800 x 600 px | Landscape photo. |

Use clear, well-lit photos in sRGB color. Keep individual files below 500 KB
when possible so the page loads quickly. Do not include private client or pet
information in the images.
